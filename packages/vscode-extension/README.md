# Momom VS Code Extension

Extensao experimental do VS Code para a linguagem Momom.

## Recursos da v0.5

- reconhecimento de arquivos `.momom`
- syntax highlighting basico
- configuracao de linguagem
- diagnostics usando `@momom/core`
- comandos para validate, show IR, show flow, preview graph e compile current file
- preview offline sem CDN

## Build

```bash
npm run build:vscode
```

## Estado atual

Esta extensao ainda nao implementa Language Server, autocomplete avancado, semantic tokens, IA ou publicacao no Marketplace.
